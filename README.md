# Дневник здоровья

Программа считает, насколько выполнены дневные цели по воде, шагам, калориям и сну.

## Что делает
- Запрашивает у пользователя: шаги, калории, воду (мл), сон (ч)
- Считает процент выполнения каждой цели
- Выводит итоговый отчёт

## Цели по умолчанию
| Показатель | Цель      |
|------------|-----------|
| Вода       | 2000 мл   |
| Шаги       | 10000     |
| Калории    | 2000      |
| Сон        | 8 ч       |

## Как запустить
```bash
python fitness-tracker.py
